# Blender Work preview artwork

Five previews were created with the built-in image-generation tool, each using a rendered view of its actual GLB model as a geometry and appearance reference. They are photographic interpretations; the interactive inspector always shows the original file.

Each native generation is 1672 × 941. The `-4k.webp` exports are 3840 × 2160, upscaled with Lanczos resampling. Responsive `-1536.webp` and `-768.webp` versions keep card downloads small. `image-sizes.json` records dimensions and byte sizes. These are upscaled 4K exports, not native 4K generations.
