# Mobile navigation brand mark

Created using the built-in imagegen tool for Manoj Poudel's mobile navigation.

- `assets/logos/branding/manoj-poudel-monogram-96.webp`: 4,554 bytes, used at 30 CSS pixels in the mobile header.
- `assets/logos/branding/manoj-poudel-monogram-144.webp`: 7,174 bytes, used at 44 CSS pixels in the menu.
- `assets/images/exports/branding/manoj-poudel-monogram-native.png`: native 1672 × 941 transparent generated image.
- `assets/images/exports/branding/manoj-poudel-monogram-4k.png`: 3840 × 2160 upscaled export; not native 4K generation. The site never loads this export.

Web versions trim the transparent margins and retain the generated mark, with enough padding for crisp small-screen display. Both themes use the same copper mark.

## Final generation prompt

Use case: logo-brand. Create a single premium personal brand logo for software engineer Manoj Poudel, to be used in a minimalist mobile portfolio navigation. Request 4K landscape output 3840x2160 if supported. A refined geometric monogram combining exactly the letters "M" and "P", balanced and clearly readable even at 32 pixels. Warm copper ink #b85a08 on perfectly flat warm ivory #fcfaf7 background. Elegant custom editorial letter construction, precise medium-weight strokes, subtly interlocking letters but never resembling random extra letters. A single monogram centered within a generous square safe area in the center of the landscape canvas; logo occupies about 50% of the image height. Flat, two-color, exceptionally sharp edges, polished modern identity design. No gradients, no 3D mockup, no texture, no metallic reflections, no shadows, no extra text, no watermark, no border, no surrounding objects. This logo should complement warm ivory cards with orange line accents and Playfair Display headings.
